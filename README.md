# 高報酬戰將 Web 0.6.3

[開啟遊戲](https://oldhenry1130.github.io/highreward-web/)

原生 JavaScript 重製，使用圖像按鈕與 595 項重新繪製的素材。六支部隊從原作的薩蘭特城開局，保留原作 8,000 G 資金與 10,000,000 G 債務。

## 0.6.3 五倍收益與敗戰恢復

- 民事、軍事、建築、公演、劇情及戰鬥所得提高為 5 倍。原作提前完成加倍、半額及分帳條件仍套用；任務看板、任務卡與報酬文字同步顯示新金額。
- 購買、薪資、還款與損失維持原值；裝備／載具轉售、退款及 Shift＋G 密技不乘倍數。現金仍有原作 99,999,999 G 上限。既有餘額不追溯乘倍數。
- 戰鬥按鈕改由視窗獨立接收點擊，提供進行中／暫停／撤退狀態；單步先暫停再只推進一回合。隊長正在退場或已退場時，連按撤退不再中斷戰鬥。
- 原作敗戰事件結算後，部隊撤回最後安全據點（失效時選其他安全據點），倒下的隊長以 1 HP 恢復可操作。裝備與傭兵傷亡保留，可駐留休養或前往病院。已停在敗戰後的舊存檔也可恢復；劇情停用的部隊不自動解鎖。
- 199 項測試通過，並完成桌面／手機按鈕、實際入帳與讀檔、完整敗戰、舊敗戰存檔及駐留回滿血的瀏覽器驗證。

收益倍率與安全據點救援為本重製版的玩法調整。更新後沿用原存檔，請確認右上角版本為 **0.6.3**。

## 0.6.2 地圖繪圖指令與卡住存檔恢復

- 修正 `fault · instruction.unsupported · Original hardware/DOS I/O is blocked`、位置 `{segment:8808,offset:4910}`。此處是原作地圖標記背景暫存的 VGA 平面選擇指令。
- 只轉接已核對的 48 處繪圖寫入，全部於 JavaScript 虛擬記憶體執行；其他 DOS／硬體指令繼續拒絕執行。
- 重新整理或匯入存檔時，會自動接續這些已確認的舊中斷點，保留原作呼叫堆疊與遊戲進度；不直接略過戰鬥或給予勝利。
- 174 項測試通過；含 12 組原始 x86 繪圖函式對照、同錯誤位置的存檔恢復與其他錯誤拒絕測試。瀏覽器實測先以 0.6.1 重現錯誤，再更新至 0.6.2，確認自動恢復與匯出進度完整。

請在原遊戲分頁重新整理；看到 **0.6.2** 即為新版。測試使用同錯誤位置的控制存檔，尚未取得玩家本人完整存檔。

## 0.6.1 戰鬥視窗修正

- 操作按鈕不再隨戰場每次更新而被替換，避免按下與放開之間點擊失效；操作列固定在視窗底部。
- 戰鬥中按關閉可選擇撤退並接回事件；結束後按關閉也會正確接回原作流程。
- 視窗頂部可直接備份存檔。載入失敗時保留原始進度，提供匯出與匯入備份。
- 170 項自動測試通過；另實測持續戰鬥的半秒點擊、桌面／手機操作列、撤退接續、結算後關閉、重新整理及戰鬥中備份。

原作戰鬥與事件規則保持原值；不需要重新開始。仍未取得個別玩家卡住時的存檔，以上驗證涵蓋可重現的介面缺陷及原作野外遭遇流程。

## 0.6 圖像編制與裝備倉庫

- 編制改用人物卡，拖曳傭兵到空位移交、拖到已有成員的位置交換；支援同城跨隊操作，隊長仍固定。
- 裝備購買先進所屬部隊倉庫，再拖給角色或傭兵。換下的裝備自動歸還倉庫；拖回倉庫可卸下，也可先點來源再點目標。
- 商店顯示單價、數量、總價及適用成員／能力變化。倉庫物品可依原作基準價半價出售。
- 城鎮標記與點選範圍放大。民事／軍事任務可點目的地，地圖自動定位、放大並閃爍 10 秒，手機會捲回地圖。
- 密技：按 **Shift＋G** 每次增加 **50,000 G**。長按不連續觸發；文字欄位中不生效；接近原作金額上限時不再增加。
- 自動接續 0.5 原作戰役存檔，使用獨立 v4 鍵避免舊分頁覆寫新倉庫；原 v3 備份不刪除。

倉庫與密技為本重製版的新增操作；原作戰鬥、地形、事件與裝備適用資格繼續沿用。168 項自動測試通過，另有桌面實際拖曳與手機點選操作驗收。

## 0.5 原作還原內容

- 戰鬥：原作能力成長、命中、傷害、射速、16 種陣形、狀態與退場動畫、個別／全隊撤退、傷亡及勝敗結算。
- 世界：128×96 地形、原作路徑與亂數、時鐘、攻城守軍、自由座標行軍、跨國交通、要道封鎖與渡船。
- 載具：車輛、飛機、火砲，原作商店的換購／出售、耐久、維修、資格、特殊戰車事件及同城移交。
- 劇情：民事、軍事、公演、建築、主線、銀行追債與薪資事件，任務期限、條件、報酬與旗標。
- 結局：償清債務後的證明、六隊依經營成果分歧的後日談、總帳與製作名單。
- 存檔：世界、對話、交易與戰鬥皆可持續保存及 JSON 備份。0.4 試作存檔另行保留，可在設定下載備份；0.6 自動接續 0.5 原作戰役進度。
- 音樂：27 首原作 MIDI 由 Web Audio 合成，先點音符啟用；原檔空白曲目維持停用。

原作主程式與 138 個區塊轉為受限的 JavaScript 指令模型；網頁不執行 Windows 或 DOS 執行檔。原作近身戰鬥另有原生規則移植。

驗證包含 603 個世界循環逐位元組比對全部 31,848 bytes、99 處據點 337 個入口／2,398 個分支節點，以及能力、戰鬥、交通、交易、任務、存檔與片尾測試。另核對開局要道封鎖與解除後的跨國飛行：26 項路徑及 5 項命令邊界與原程式一致。瀏覽器實測含開場、整備、移交、飛機購買到站、銀行戰鬥撤退、讀檔與片尾。

## 操作

點選下方部隊或按 1–6；選城鎮或地圖空白處下達行軍。空白鍵暫停。整備頁可點成員查看數值，城鎮圖示開啟原作設施。攻城及交通依原作資格開放；有飛機不代表封鎖路線已解除。城鎮休養須推進時間。

本版保留原作資料與規則，畫面、操作節奏與音色採瀏覽器呈現。並非所有長期遊玩組合均已窮舉；DOS 存檔不與 Web JSON 互通。原檔少數文字含無效 Big5 位元組，可能顯示替代字元。片尾以按鈕推進、確認結束。
