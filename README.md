# 高報酬戰將 Web 重製開發版

[開啟遊戲](https://oldhenry1130.github.io/highreward-web/)

以瀏覽器直接遊玩的原生 JavaScript 重製版，保留原作名稱、主要配色與美術風格，改用圖像按鈕與新版素材。

- 595 種獨立圖像皆已重製與驗收，包括 92 筆頭像素材（含原本空白佔位）、地圖、場景、角色動作、圖示與效果。
- 複雜圖像使用內建影像生成工具重畫；簡單介面與幾何效果以 SVG 手工重製。
- 少數服裝採較保守設計，一張舞台圖改用完整服裝及新構圖；微小文字與圖案屬視覺重建。
- 網頁用 WebP 圖片採無失真轉換，已核對解碼後的 RGBA 像素；SVG 可直接縮放。
- 此為重製開發版，戰役規則、數值、故事與原作的完整對照仍未完成。

選擇下方部隊，使用酒館招募、武器商店與委託看板開始遊玩。空白鍵暫停，1–6 切換部隊。進度保存在目前瀏覽器；請使用設定中的 JSON 匯出功能備份與跨裝置移轉。
